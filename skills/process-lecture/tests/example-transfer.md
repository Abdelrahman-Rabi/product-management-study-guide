# Scenario: Transferable Practical Example

## Prompt

The user supplies a Level 2 transcript about testing assumptions before committing a roadmap item.

## Expected Without Skill

The agent may add a generic SaaS story that mentions discovery but does not expose the Product Manager's reasoning or demonstrate the lecture concept.

## Required Behavior With Skill

- Use an example that directly supports the primary learning outcome.
- Show the situation, decision, reasoning, consequence, and transferable lesson.
- Make clear which transcript-grounded concept the example demonstrates.
- Keep the example shorter than the lesson it supports.
- Revise or replace a decorative example whose connection cannot be made clear; do not omit the required Level 2 example or invent unsupported lecture claims.

## Pass Condition

The learner can see how the lecture's mental model changes a realistic Product Management decision and can transfer that reasoning to a similar situation.
