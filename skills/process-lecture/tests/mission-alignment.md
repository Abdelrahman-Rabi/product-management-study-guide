# Scenario: Mission-Aligned Lecture

## Prompt

The user supplies a complete transcript about deciding whether a requested feature addresses a meaningful customer problem.

## Expected Without Skill

The agent may produce a complete summary without connecting the lecture to the learner's practical Product Management goals.

## Required Behavior With Skill

- Select one relevant success criterion from `LEARNING-MISSION.md`.
- Use that criterion to guide the learning outcome, example, and emphasis.
- Keep the lecture's claims grounded only in the transcript.
- Avoid repeating the entire learning mission inside the published guide.
- Do not use the mission as evidence for a claim the instructor did not make.

## Pass Condition

The guide clearly develops a mission-relevant Product Management capability while preserving the transcript-only content boundary.
