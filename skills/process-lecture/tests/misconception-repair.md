# Scenario: Misconception Repair

## Prompt

The user supplies a transcript explaining that outcome roadmaps should avoid premature commitment to features. The claim could be oversimplified as "features do not matter."

## Expected Without Skill

The agent may list the misconception and deny it without explaining why it sounds plausible or how the corrected model affects Product Management behavior.

## Required Behavior With Skill

- Include the misunderstanding only because the transcript supports a plausible source of confusion.
- State the misconception precisely.
- Explain why the misconception can appear plausible.
- Supply the correct transcript-grounded mental model.
- Explain the decision or behavior that changes when the learner adopts the correct model.
- Avoid introducing an unrelated framework.

## Pass Condition

The correction helps the learner diagnose and avoid a realistic decision error rather than merely memorizing that a statement is false.
