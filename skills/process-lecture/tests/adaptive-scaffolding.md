# Scenario: Adaptive Scaffolding

## Prompt

The user supplies a foundational lecture connecting technical delivery practices to Product Management discovery. Existing repository material and `LEARNING-MISSION.md` document a software-development background but provide no evidence of discovery mastery.

## Expected Without Skill

The agent may either reteach basic software delivery concepts at length or assume that technical experience proves familiarity with Product Management discovery.

## Required Behavior With Skill

- Assess concept complexity and learner familiarity separately.
- Treat software delivery as established or adjacent only where documented.
- Treat Product Management discovery as unfamiliar unless stronger evidence exists.
- Use a concise technical bridge where useful and state where the analogy stops.
- Provide the minimum prerequisite scaffolding needed for the new mental model.
- Do not lower the material level merely because part of the context is familiar.

## Pass Condition

The guide avoids redundant technical explanation while supplying enough Product Management scaffolding to make the foundational lecture understandable.
