# Product Management Study Guide

This repository transforms Product Management video-course transcripts into a
structured, connected, practical, and visually supported knowledge base.

The goal is to make every lecture understandable and reviewable without needing
to rewatch the original video.

## What This Repository Contains

- Structured lecture study guides
- Practical Product Management examples
- Visual illustrations embedded inside lecture notes
- Section summaries
- Section mind maps
- Part summaries
- Part mind maps
- A shared Product Management glossary
- A course-wide concept map
- A visual index
- Original lecture transcripts stored separately from polished notes
